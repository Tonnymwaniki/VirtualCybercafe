# Virtual Cybercafe

Virtual Cybercafe is a mobile app for Android and iOS. This repository holds the starter project; features will be added once the platform is described.

## Stack

- [Expo](https://expo.dev) (React Native)
- TypeScript

## Getting started

```bash
npm install
npm start        # starts the Expo dev server; scan the QR code with Expo Go
npm run android  # open on an Android device or emulator
npm run ios      # open on an iOS simulator (macOS only)
```

## Project layout

- `App.tsx`: the root screen
- `index.ts`: app entry point
- `app.json`: Expo app configuration (name, icons, splash)
- `assets/`: icons and splash images
